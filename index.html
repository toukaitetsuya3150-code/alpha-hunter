方法论 / METHODOLOGY

综合得分 S = w1·动量 + w2·量能 + w3·估值 + w4·风险，每个因子在股票池内做横截面标准化（z-score）后加权合成—— 这正是量化私募"多因子选股"的最小可用内核。
动量 = 当日涨幅 与 价格所处日内区间位置（靠近最高价为强）； 量能 = 量比 × 换手率的活跃度合成（放量确认趋势）； 估值 = PE(TTM) 反向得分（池内越便宜分越高）； 风险 = 振幅与市值波动性的反向得分（低波动+大市值加分）。
智能选股流水线：沪深A股成交额前400 → 硬过滤（剔除ST/停牌/亏损/PE超限/市值过低/量比不足/涨停追高/暴跌接刀）→ z-score 因子合成 → Top20。
回测训练（近一年2896个交易日样本）：A股短周期呈反转效应——量能反向（缩量回踩优于放量追高）、动量无效、低波动占优；优化组合 IC=+0.070（t=3.60，日胜率63%），点击左侧「🧠 应用回测优化权重」一键载入。
大事件日历（FOMC等）前7天自动进入防护模式：风险因子权重×1.5。
底部突破引擎：基本面（PE 5-40 + 市值≥100亿）× 底部震荡（60日涨幅-15%~+8% 且年内涨幅<20%）× 放量启动（量比≥1.5 + 涨幅0.5%~9.4% + 收在日内上半区），三维共振才入选。
主线板块引擎：行业板块按近60日涨幅取Top6（=月内主线）→ 逐板块取成交额Top15成分股 → 硬过滤（盈利/市值≥80亿/非涨停）→ 因子打分，★ 标记各板块综合分第一的龙头推荐。
交易价格引擎：以今日高/低/昨收计算枢轴点 P=(H+L+C)/3、支撑 S1=2P-H、压力 R1=2P-L → 买=支撑位低吸价（强票给回踩价、弱票给支撑确认价），损=支撑下方1.8%，T卖=压力位，T接=回到枢轴点。
信号分级：强烈关注 ≥70 关注 50-70 回避 <50
